# Dungeon Stake sprite brief

Subjects: Knight (sword), Archer (bow), Mage (staff), Barbarian (axe), Rogue (dagger), demon Boss, Orc, Goblin, Skeleton, Dark Mage; grass path and stone floor tiles.
Defaults: original chunky RPG style, readable proportions, front view, adventurous mood, 32px heroes/enemies, 48px boss, 16px tiles, shared locked material ramps, transparent PNG characters. Native backend, 1x sheet exports. CSS scales the assets.

## Done criteria
- [x] Each class has a readable weapon or distinct silhouette. Reviewed enlarged previews: sword/shield, bow, staff, axe, dagger, wings/horns, cleaver, ears/shiv, skull/blade, cursed red staff.
- [x] Heroes and enemies read as different factions. Humans contrast with the winged boss, green creatures and skeletal face; the dark mage is marked by its red staff.
- [x] One top-left light and locked material ramps; no anti-aliasing. The native kit applies consistent directional shading and hard alpha. Characters deliberately use more than the suggested 4–8 colors to retain distinct equipment materials.
- [x] Ten static characters and two opaque repeatable tiles export at native size. Nine 32x32, boss 48x48, tiles 16x16. Only sheet.png is used in game.

Review round 1: character previews inspected individually. No external image model or upscaled engine assets used. The skill's native renderer and gallery outputs were generated successfully.
